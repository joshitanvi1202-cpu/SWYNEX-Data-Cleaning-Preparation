# SWYNEX Data Cleaning & Preparation

## Objective
The objective of this project is to clean and prepare a sales dataset for analysis.

## Tools Used
- Python
- Pandas
- Google Colab
- GitHub

## Data Cleaning Steps
1. Checked the dataset for missing values.
2. Identified duplicate records.
3. Removed duplicate rows.
4. Filled missing Quantity values using the median.
5. Filled missing Price values using the median.
6. Replaced missing City values with "Unknown".
7. Verified the cleaned dataset and data types.

## Result
The dataset was cleaned successfully and is ready for further data analysis.

The cleaned dataset is available in:
`SWYNEX_Cleaned_Sales_Data.csv`
